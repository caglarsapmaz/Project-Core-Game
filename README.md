# 💻 Project: CORE - C# Training Simulator

**Project: CORE**, temel C# programlama mantığını siber güvenlik ve yapay zeka temalı etkileşimli bir hikaye üzerinden öğreten, web tabanlı bir eğitim simülasyonudur. Oyuncular (Ajanlar), uzay istasyonundaki hasarlı bir yapay zekayı onarmak için C# kodları yazarak görevleri tamamlamaya çalışırlar.

🌐 [Project: CORE'u Canlı Oyna](https://project-core-game.vercel.app/)

## 🚀 Özellikler

* **Kapsamlı C# Simülasyonu:** JavaScript ile yazılmış özel bir doğrulama motoru sayesinde C# kodlarını (Tür Dönüşümleri, String Manipülasyonu, If-Else, Random, Math) katı sözdizimi kurallarıyla (Case Sensitivity, noktalı virgül zorunluluğu) denetler.
* **Ghost Coder (Sanal Mentor):** Kullanıcı hata yaptığında anında devreye giren gelişmiş bir algoritma (LCS - Longest Common Subsequence). Kullanıcının yazdığı kod ile doğru kod arasındaki farkı karakter karakter bulur, hatalı yerleri kırmızı ile silip doğru kodu yeşil bir daktilo efektiyle ekrana canlı olarak yazar.
* **Dinamik Puanlama & Hata Analizi:** Kullanıcının ilk deneme başarısına ve kodunun doğruluk oranına göre dinamik (10-100 arası) XP hesaplaması yapar.
* **Sıralama (Leaderboard):** Görevleri tamamlayan ajanların skorlarını listeler ve en iyileri belirler.

## 🛠️ Kullanılan Teknolojiler

* **HTML5** (Semantik yapı ve tek dosya mimarisi)
* **CSS3** (Karanlık Hacker Terminali estetiği, Neon UI, Scanline efektleri ve CSS Animasyonları)
* **Vanilla JavaScript** (Tüm oyun motoru, DOM manipülasyonu ve Diff algoritmaları hiçbir kütüphane kullanılmadan tamamen native yazılmıştır.)

## 🎮 Kurulum ve Kullanım

Proje tamamen istemci tarafında (Client-side) çalışır ve herhangi bir sunucu veya bağımlılık (npm, node vb.) gerektirmez. Doğrudan tarayıcı üzerinden oynanabilir.

📝 Görev Listesi (Levels)

*Veri Dönüşümü (String to Int / Casting)

*String Manipülasyonu (ToUpper, Trim)

*Mantıksal Karşılaştırmalar (if-else)

*Dinamik Değer Üretimi (Random Sınıfı)

*Matematiksel Modüller (Math.Sqrt)
